의뢰 내용 + 내 제안가

제목/설명/위치/일시 + inDrive 스타일 슬라이더로 자유 가격 제안.

  • 4개 입력 필드: 제목, 설명, 위치, 희망 일시

5. 상태 머신 (State Machine)

Task는 4단계 생명주기를 가집니다. Supabase tasks.status 컬럼에 저장됩니다.

① OPEN

사용자가 호출하기 클릭 → task INSERT → Realtime broadcast 시작

② NEGOTIATING

워커들이 counter-offer INSERT → offers 테이블에 누적

③ ACCEPTED

사용자가 워커 수락 → status 업데이트, 매칭 확정

④ COMPLETED

작업 완료 → 평점/리뷰 활성화, payment_status 업데이트

액션 UI 컴포넌트 JS 핸들러 API / 테이블 상태 변경

호출하기 클릭 #btn-submit-request submitRequest() POST /rest/v1/tasks tasks.status = OPEN
워커 매칭 #offers-list simulateWorkerOffers() stub: setTimeout + Realtime 시뮬레이션 offers INSERT
수락 버튼 .btn-primary acceptOffer(offerId) PATCH /rest/v1/tasks tasks.status = ACCEPTED, selected_worker_id 설정
재협상 .btn-warn counterOffer(price) POST /rest/v1/offers (역방향) offers.status = COUNTERED
거절 .btn-bad declineOffer(offerId) PATCH /rest/v1/offers offers.status = DECLINED
언어 전환 .lang-opt switchLanguage(lang) localStorage.golive_lang 7개 언어 (ko/en/vi/ja/zh/hi/es)
